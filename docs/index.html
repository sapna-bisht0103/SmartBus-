C++ OOP

OOP Concepts Used

Ye project C++ ke sare important OOP concepts demonstrate karta hai

01

Encapsulation

Private data members + public getters/setters. Password aur sensitive data secure.

private: string password;
public: void login();
02

Inheritance

Student, Driver, Admin — teeno User base class se inherit karte hain.

class Student : public User {};
class Driver : public User {};
03

Polymorphism

Har user ka dashboard() alag hota hai — virtual functions se.

virtual void displayDashboard();
// Override in each class
04

Abstraction

Pure virtual function User mein — internal logic user se hidden.

virtual void displayDashboard() = 0;
// Must implement
05

Constructors

Har class mein parameterized constructor se object initialize hota hai.

Bus(string bn, int cap,
string rid, string did);
06

File Handling

Data permanently store hota hai 7 .txt files mein using fstream.

ofstream file("data/buses.txt");
file << bus.toFileString();
